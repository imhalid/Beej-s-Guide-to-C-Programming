11 Pointer'lar II: Aritmetik

Yeni pointer konularıyla konunun daha da derinlerine inme zamanı! Eğer pointer'lar konusunda henüz tam değilseniz, rehberin bu konudaki ilk bölümüne göz atın.

11.1 Pointer Aritmetiği

Meğer pointer'lar üzerinde matematik yapabiliyormuşuz; özellikle de toplama ve çıkarma.

Peki bunu yaptığınızda bu ne anlama gelir?

Kısacası, bir türe pointer'ınız varsa, pointer'a bir eklemek bellekte hemen ardından gelen bir sonraki aynı türden elemana geçmenizi sağlar.

Pointer'ları hareket ettirip bellekteki farklı yerlere bakarken, dereference etmeden (gösterdiği değere erişmeden) önce her zaman geçerli bir bellek konumunu gösterdiğimizden emin olmamız gerektiğini hatırlamak önemlidir. Eğer sınırı aşıp yoldan saparsak ve orada ne olduğuna bakmaya çalışırsak, davranış tanımsızdır (undefined behavior) ve genellikle programın çökmesiyle sonuçlanır.

Bu durum aşağıdaki Dizi/Pointer Eşdeğerliği konusuyla biraz yumurta-tavuk ikilemi gibidir, ama yine de bir şans vereceğiz.

11.1.1 Pointer'lara Ekleme Yapmak

İlk olarak bir sayı dizisi ele alalım.

int a[5] = {11, 22, 33, 44, 55};

Ardından bu dizinin ilk elemanını gösteren bir pointer alalım:

int a[5] = {11, 22, 33, 44, 55};

int *p = &a[0];  // Veya "int *p = a;" da aynı şekilde çalışır

Şimdi pointer'ı dereference ederek oradaki değeri yazdıralım:

printf("%d\n", *p);  // 11 yazdırır

Şimdi dizideki bir sonraki elemanı, yani 1 indeksindeki elemanı yazdırmak için pointer aritmetiğini kullanalım:

printf("%d\n", *(p + 1));  // 22 yazdırır!!

Orada ne oldu? C, p'nin bir int pointer'ı olduğunu bilir. Dolayısıyla bir int türünün sizeof değerini bilir84 ve ilk int'ten sonraki bir sonraki int'e ulaşmak için kaç bayt atlaması gerektiğini bilir!

Hatta önceki örnek şu iki eşdeğer şekilde yazılabilirdi:

printf("%d\n", *p);        // 11 yazdırır
printf("%d\n", *(p + 0));  // 11 yazdırır

çünkü bir pointer'a 0 eklemek yine aynı pointer'ı verir.

Buradaki asıl kazancı düşünelim. Dizi indeksleri kullanmak yerine bu şekilde bir dizinin elemanları üzerinde gezinebiliriz (iterate edebiliriz):

int a[5] = {11, 22, 33, 44, 55};

int *p = &a[0];  // Veya "int *p = a;" da aynı şekilde çalışır

for (int i = 0; i < 5; i++) {
    printf("%d\n", *(p + i));  // p[i] ile aynı!
}

Ve bu, dizi notasyonunu kullanmışız gibi aynı şekilde çalışır! Oooo! Şu dizi/pointer eşdeğerliği mevzusuna giderek yaklaşıyoruz! Bu bölümde ilerleyen kısımlarda bununla ilgili daha fazlasını göreceğiz.

Peki burada gerçekte ne oluyor? Nasıl çalışıyor?

Erken konularımızdan hatırlayın: bellek, her dizi indeksinde bir baytın saklandığı büyük bir dizi gibidir.

Ve bellekteki bu dizi indeksinin birkaç farklı adı vardır:

  • Bellek indeksi
  • Konum (Location)
  • Adres
  • Pointer! (Gösterici)

Yani bir pointer, bellekteki herhangi bir yerin indeksidir.

Rastgele bir örnek vermek gerekirse, diyelim ki 3490 sayısı 23.237.489.202 adresinde ("indeksinde") saklanıyor. O 3490 sayısını gösteren bir int pointer'ımız varsa, o pointer'ın değeri 23.237.489.202'dir... çünkü pointer bellek adresinin kendisidir. Aynı şey için farklı sözcükler.

Şimdi de 3490'ın hemen arkasından 23.237.489.210 adresinde saklanan başka bir sayımız, 4096 olsun (3490'dan 8 fazla, çünkü bu örnekteki her int 8 bayt uzunluğundadır).

Eğer o pointer'a 1 eklersek, gerçekte bir sonraki int'e ulaşmak için sizeof(int) bayt kadar ileri atlar. O kadar ileri atlayacağını bilir çünkü o bir int pointer'ıdır. Bir float pointer'ı olsaydı, bir sonraki float'a geçmek için sizeof(float) bayt ileri atlardı!

Böylece pointer'a 1 ekleyerek bir sonraki int'e, 2 ekleyerek ondan sonrakine bakabilirsiniz, bu böyle devam eder.

11.1.2 Pointer'ları Değiştirmek

Önceki bölümde bir pointer'a tamsayı ekleyebileceğimizi gördük. Bu sefer pointer'ın kendisini değiştirelim.

Herhangi bir pointer'a doğrudan tamsayı değerleri ekleyebilir (veya çıkarabilirsiniz)!

Aynı örneği birkaç değişiklikle tekrar yapalım. İlk olarak, gözcü/bitiş değeri (sentinel value) olarak kullanmak üzere sayılarımızın sonuna bir 999 ekleyeceğim. Bu, verilerin nerede bittiğini anlamamızı sağlayacak.

int a[] = {11, 22, 33, 44, 55, 999};  // Bitiş değeri (sentinel) olarak buraya 999 ekleyin

int *p = &a[0];  // p, 11'i gösterir

Tıpkı daha önceki gibi, a'nın 0 indeksindeki elemanını, yani 11'i gösteren bir p pointer'ımız var.

Şimdi p'yi dizinin sonraki elemanlarını gösterecek şekilde artırmaya başlayalım. Bunu p, 999'u gösterene kadar yapacağız; yani *p == 999 olana kadar devam edeceğiz:

while (*p != 999) {       // p'nin gösterdiği şey 999 olmadığı sürece
    printf("%d\n", *p);   // Yazdır
    p++;                  // p'yi bir sonraki int'i gösterecek şekilde ilerlet!
}

Çok çılgınca, değil mi?

Çalıştırdığımızda, önce p, 11'i gösterir. Sonra p'yi artırırız ve 22'yi gösterir, sonra tekrar artırırız 33'ü gösterir. Ve 999'u gösterene kadar bu şekilde devam eder ve döngüden çıkarız.

11.1.3 Pointer Çıkarma

Tıpkı ekleme yaptığımız gibi, daha önceki bir adrese ulaşmak için bir pointer'dan değer de çıkarabilirsiniz.

Ancak iki pointer arasındaki farkı bulmak için onları birbirinden de çıkarabiliriz; örneğin iki int* arasında kaç tane int olduğunu hesaplayabiliriz. Buradaki püf nokta, bunun yalnızca tek bir dizi içinde çalışmasıdır85—pointer'lar başka şeyleri gösteriyorsa tanımsız davranış (undefined behavior) elde edersiniz.

C'de metin dizilerinin (string) char* olduğunu hatırlıyor musunuz? Pointer çıkarmasını kullanarak bir string'in uzunluğunu hesaplayan strlen() fonksiyonunun başka bir varyasyonunu yazıp yazamayacağımıza bakalım.

Fikir şu: String'in başına işaret eden bir pointer'ımız varsa, NUL karakterini arayarak string'in sonuna işaret eden pointer'ı bulabiliriz.

Ve elimizde hem string'in başlangıcını gösteren pointer hem de sonunu gösteren pointer varsa, uzunluğu elde etmek için bu iki pointer'ı birbirinden çıkarmamız yeterlidir!

#include <stdio.h>

int my_strlen(char *s)
{
    // String'in başından taramaya başla
    char *p = s;

    // NUL karakterini bulana kadar tara
    while (*p != '\0')
        p++;

    // Pointer'lar arasındaki farkı döndür
    return p - s;
}

int main(void)
{
    printf("%d\n", my_strlen("Hello, world!"));  // "13" yazdırır
}

Pointer çıkarmasını yalnızca aynı diziyi gösteren iki pointer arasında kullanabileceğinizi unutmayın!

11.2 Dizi/Pointer Eşdeğerliği

Sonunda bundan bahsetmeye hazırız! Dizi notasyonunu harmanladığımız pek çok örnek gördük, ancak şimdi dizi/pointer eşdeğerliğinin temel formülünü verelim:

a[b] == *(a + b)

Bunu iyi inceleyin! Bunlar birbirine eşdeğerdir ve birbirinin yerine kullanılabilir!

Biraz basitleştirdim, çünkü yukarıdaki örneğimde a ve b ifadeler (expressions) olabilir ve ifadeler karmaşıksa işlem sırasını zorlamak için birkaç parantez daha eklemek isteyebiliriz.

Standart bildiğiniz gibi her zamanki netliğiyle (C11 §6.5.2.1¶2 altında) şunu beyan eder:

E1[E2] ifadesi (*((E1)+(E2))) ile birebir aynıdır.

ama bunu kavramak biraz daha zordur. İfadeler karmaşıksa, tüm matematiğin doğru sırada gerçekleşmesi için parantez eklediğinizden emin olun.

Bu, herhangi bir dizi veya pointer için (bir dizinin bir elemanını gösterdiğini varsayarsak) dizi veya pointer notasyonu kullanıp kullanmayacağımıza karar verebileceğimiz anlamına gelir.

Hem dizi hem de pointer notasyonunu bir dizi ve pointer ile birlikte kullanalım:

#include <stdio.h>

int main(void)
{
    int a[] = {11, 22, 33, 44, 55};

    int *p = a;  // p, a'nın ilk elemanını (11) gösterir

    // Dizinin tüm elemanlarını çeşitli yollarla yazdırın:

    for (int i = 0; i < 5; i++)
        printf("%d\n", a[i]);      // a ile dizi notasyonu

    for (int i = 0; i < 5; i++)
        printf("%d\n", p[i]);      // p ile dizi notasyonu

    for (int i = 0; i < 5; i++)
        printf("%d\n", *(a + i));  // a ile pointer notasyonu

    for (int i = 0; i < 5; i++)
        printf("%d\n", *(p + i));  // p ile pointer notasyonu

    for (int i = 0; i < 5; i++)
        printf("%d\n", *(p++));    // p pointer'ını ilerletme
        //printf("%d\n", *(a++));    // a dizi değişkenini ilerletme--HATA!
}

Gördüğünüz gibi genel olarak bir dizi değişkeniniz varsa, elemanlara erişmek için pointer veya dizi notasyonunu kullanabilirsiniz. Aynı şey pointer değişkeni için de geçerlidir.

En büyük tek fark, bir pointer'ı farklı bir adresi gösterecek şekilde değiştirebilmeniz, ancak bunu bir dizi değişkeni ile yapamamanızdır. Başka bir deyişle, bir dizi değişkeninin kendisine atama yapamazsınız; yalnızca o dizinin bireysel elemanlarına atama yapabilirsiniz.

Bir diziyi diğerine gerçekten kopyalamak istiyorsanız, bunu gerçekleştirmek için memcpy() gibi bir fonksiyon (veya bir döngü) kullanmanız gerekir.

11.2.1 Fonksiyon Çağrılarında Dizi/Pointer Eşdeğerliği

Bu kavramla kesinlikle en çok karşılaşacağınız yer burasıdır.

Pointer argümanı alan bir fonksiyonunuz varsa, örneğin:

int my_strlen(char *s)

bu, bu fonksiyona hem bir dizi hem de bir pointer geçebileceğiniz ve çalışmasını sağlayabileceğiniz anlamına gelir!

char s[] = "Antelopes";
char *t = "Wombats";

printf("%d\n", my_strlen(s));  // Çalışır!
printf("%d\n", my_strlen(t));  // Bu da çalışır!

Ve bu iki fonksiyon imzasının eşdeğer olmasının nedeni de budur:

int my_strlen(char *s)    // Çalışır!
int my_strlen(char s[])   // Bu da çalışır!

11.3 void Pointer'ları

Fonksiyonlarda parametre olmadığını veya geri dönüş değeri olmadığını belirten void anahtar kelimesini zaten gördünüz, ancak bu tamamen ayrı ve ilişkisiz bir konudur.

Bir void* kesinlikle var olan bir şeyi gösteren bir pointer'dır. Ancak void kısmı, o şeyin türünü bilmediğimizi gösterir. Ve bazen, ister inanın ister inanmayın, bu gerçekten yararlıdır. C gibi tür korumalı bir dilde sahip olunması güzel bir esneklik olan, türden biraz daha bağımsız kod yazmamızı sağlar.

Bunun için temel olarak iki kullanım senaryosu vardır; gelin bunlara göz atalım ve gizemini biraz çözebilecek miyiz bakalım.

  1. Bir fonksiyon bir nesne üzerinde bayt bayt işlem yapacaktır. Örneğin, memcpy() bir pointer'dan diğerine bellek baytlarını kopyalar, ancak bu pointer'lar herhangi bir türü gösterebilir. memcpy(), nesnenin türü ne olursa olsun char* pointer'ları üzerinde gezinirseniz bir nesnenin baytları üzerinde gezinmiş olacağınız gerçeğinden yararlanır. Bu konu hakkında daha fazla bilgiyi Çoklu Bayt Değerleri alt bölümünde bulabilirsiniz.

  2. Başka bir fonksiyon, ona geçirdiğiniz bir fonksiyonu (geri çağırma / callback) çağırıyordur ve size veri aktarıyordur. Siz verinin türünü bilirsiniz ama sizi çağıran fonksiyon bilmez. Bu yüzden türü bilmediğinden size void* geçirir ve siz de bunları ihtiyacınız olan türe dönüştürürsünüz. C'de yerleşik olan qsort()86 ve bsearch()87 bu tekniği kullanır.

Bir örneğe, yerleşik memcpy() fonksiyonuna bakalım:

void *memcpy(void *s1, void *s2, size_t n);

Bu fonksiyon, s2 adresinden başlayan belleğin n baytını s1 adresinden başlayan belleğe kopyalar.

Ama bakın! s1 ve s2 birer void*! Neden? Bu ne anlama geliyor? Görmek için daha fazla örnek çalıştıralım.

Örneğin, memcpy() ile bir string kopyalayabiliriz (gerçi string'ler için strcpy() daha uygundur):

#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "Goats!";
    char t[100];

    memcpy(t, s, 7);  // 7 bayt kopyala--NUL sonlandırıcı dahil!

    printf("%s\n", t);  // "Goats!"
}

Veya birkaç int kopyalayabiliriz:

#include <stdio.h>
#include <string.h>

int main(void)
{
    int a[] = {11, 22, 33};
    int b[3];

    memcpy(b, a, 3 * sizeof(int));  // 3 int verisi kopyala

    printf("%d\n", b[1]);  // 22
}

Bu biraz çılgınca—orada memcpy() ile ne yaptığımızı gördünüz mü? Verileri a'dan b'ye kopyaladık, ancak kaç bayt kopyalanacağını belirtmemiz gerekti ve bir int bir bayttan fazladır.

Peki öyleyse—bir int kaç bayt kaplar? Yanıt: sisteme bağlıdır. Ancak sizeof operatörü ile herhangi bir türün kaç bayt kapladığını öğrenebiliriz.

İşte cevap: Bir int saklamak için sizeof(int) bayt bellek gerekir.

Ve dizimizde o örnekte yaptığımız gibi bunlardan 3 tane varsa, 3 int için kullanılan toplam alan 3 * sizeof(int) olmalıdır.

(Daha önceki string örneğinde, 7 * sizeof(char) bayt kopyalamak teknik olarak daha doğru olurdu. Ancak char türü tanım gereği her zaman bir bayt büyüklüğündedir, dolayısıyla bu basitçe 7 * 1 haline gelir.)

Hatta memcpy() ile bir float veya bir struct (yapı) bile kopyalayabiliriz! (Gerçi bu biraz kötüye kullanımdır—bunun için = kullanmalıyız):

struct antelope my_antelope;
struct antelope my_clone_antelope;

// ...

memcpy(&my_clone_antelope, &my_antelope, sizeof my_antelope);

memcpy()'nin ne kadar çok yönlü olduğuna bakın! Bir kaynağa işaret eden bir pointer'ınız, bir hedefe işaret eden bir pointer'ınız ve kopyalamak istediğiniz bayt sayınız varsa, her türden veriyi kopyalayabilirsiniz.

void* yapısına sahip olmadığımızı hayal edin. Her tür için özel memcpy() fonksiyonları yazmamız gerekirdi:

memcpy_int(int *a, int *b, int count);
memcpy_float(float *a, float *b, int count);
memcpy_double(double *a, double *b, int count);
memcpy_char(char *a, char *b, int count);
memcpy_unsigned_char(unsigned char *a, unsigned char *b, int count);

// vb... ıyy!

Sadece void* kullanmak ve hepsini yapabilen tek bir fonksiyona sahip olmak çok daha iyidir.

İşte void*'ın gücü budur. Değişkenin türünü önemsemeyen ve yine de onunla işlemler yapabilen bir fonksiyon yazabilirsiniz.

Ancak büyük güç büyük sorumluluk getirir. Bu durumda belki o kadar büyük bir sorumluluk değil ama yine de bazı sınırlar vardır.

  1. Bir void* üzerinde pointer aritmetiği yapamazsınız.
  2. Bir void*'ı dereference edemezsiniz (gösterdiği değeri alamazsınız).
  3. Bir void* üzerinde ok (arrow, ->) operatörünü kullanamazsınız, çünkü o da bir dereference işlemidir.
  4. Bir void* üzerinde dizi notasyonunu kullanamazsınız, çünkü o da bir dereference işlemidir88.

Düşündüğünüzde bu kurallar mantıklıdır. Tüm bu işlemler gösterilen verinin türünün sizeof değerini bilmeye dayanır ve void* ile gösterilen verinin boyutunu bilmeyiz—her şey olabilir!

Ama bekleyin—bir void*'ı dereference edemiyorsanız, ne işinize yarayabilir ki?

Tıpkı memcpy()'de olduğu gibi, birden fazla veri türünü işleyebilen jenerik (genel) fonksiyonlar yazmanıza yardımcı olur. İşin sırrı ise şudur: Derinlerde, kullanmadan önce void* türünü başka bir türe dönüştürürsünüz!

Ve dönüşüm kolaydır: İstenen türdeki bir değişkene atama yapmanız yeterlidir89.

char a = 'X';  // Tek bir char

void *p = &a;  // p, 'X' karakterini gösterir
char *q = p;   // q da 'X' karakterini gösterir

printf("%c\n", *p);  // HATA--void* dereference edilemez!
printf("%c\n", *q);  // "X" yazdırır

Bunu denemek için kendi memcpy() fonksiyonumuzu yazalım. Baytları (char) kopyalayabiliriz ve bayt sayısını biliyoruz çünkü parametre olarak geçirildi.

void *my_memcpy(void *dest, void *src, int byte_count)
{
    // void* türlerini char*'a dönüştür
    char *s = src, *d = dest;

    // Artık char*'larımız olduğuna göre dereference edip kopyalayabiliriz
    while (byte_count--) {
        *d++ = *s++;
    }

    // Bu fonksiyonların çoğu, çağıran kişiye yararlı olabilmesi ihtimaline karşı
    // hedefi (destination) döndürür.
    return dest;
}

Tam oranın başında, onları char* olarak kullanabilmemiz için void* değerlerini char* içine kopyalıyoruz. İşte bu kadar kolay.

Ardından byte_count değişkenini yanlış (0) olana kadar azalttığımız eğlenceli bir while döngüsü geliyor. Sonradan eksiltmede (post-decrement), ifadenin değerinin hesaplandığını (while kullanımı için) ve sonrasında değişkenin eksiltildiğini hatırlayın.

Kopyalama aşamasındaki eğlencede ise baytı kopyalamak için *d = *s atamasını yapıyoruz, ancak bunu sonradan artırma (post-increment) ile yapıyoruz, böylece atama yapıldıktan sonra hem d hem de s bir sonraki bayta ilerliyor.

Son olarak, bellek ve string fonksiyonlarının çoğu, çağıranın kullanmak istemesi durumunda hedefe giden pointer'ın bir kopyasını döndürür.

Bunu yaptığımıza göre, C'deki herhangi bir nesnenin (float, struct veya başka herhangi bir şey!) baytları üzerinde gezinmek için bu tekniği kullanabileceğimizi hemen belirtmek isterim!

Gelin void* sihirbazlığı sayesinde her şeyi sıralayabilen yerleşik qsort() yordamı ile gerçek dünyadan bir örnek daha çalıştıralım.

(Aşağıdaki örnekte, henüz işlemediğimiz const kelimesini göz ardı edebilirsiniz.)

#include <stdio.h>
#include <stdlib.h>

// Sıralayacağımız yapı (struct) türü
struct animal {
    char *name;
    int leg_count;
};

// Bu, neye göre sıralayacağını belirlemesine yardımcı olmak için
// qsort() tarafından çağrılan bir karşılaştırma fonksiyonudur. Bunu, struct
// animal dizisini leg_count'a göre sıralamak için kullanacağız.
int compar(const void *elem1, const void *elem2)
{
    // struct animal nesnelerini sıraladığımızı biliyoruz, bu nedenle her iki
    // argümanı da struct animal pointer'ı yapalım
    const struct animal *animal1 = elem1;
    const struct animal *animal2 = elem2;

    // Neye göre sıralamak istiyorsak ona bağlı olarak <0 =0 veya >0 döndürün.

    // leg_count'a göre artan sırada sıralayalım, bu nedenle leg_count
    // farkını döndüreceğiz
    if (animal1->leg_count > animal2->leg_count)
        return 1;
    
    if (animal1->leg_count < animal2->leg_count)
        return -1;

    return 0;
}

int main(void)
{
    // Farklı özelliklere sahip 4 struct animal dizisi oluşturalım. Bu
    // dizi leg_count değerine göre sırasızdır, ancak birazdan sıralayacağız.
    struct animal a[4] = {
        {.name="Dog", .leg_count=4},
        {.name="Monkey", .leg_count=2},
        {.name="Antelope", .leg_count=4},
        {.name="Snake", .leg_count=0}
    };

    // Diziyi sıralamak için qsort() fonksiyonunu çağırın. qsort()'a bu
    // verileri neye göre sıralayacağı tam olarak söylenmelidir ve bunu
    // compar() fonksiyonu içinde yapacağız.
    //
    // Bu çağrı şunu söyler: 4 elemanı olan ve her elemanı sizeof(struct animal)
    // bayt büyüklüğünde olan a dizisini qsort ile sırala ve iki elemanı
    // karşılaştıracak fonksiyon budur.
    qsort(a, 4, sizeof(struct animal), compar);

    // Hepsini ekrana yazdır
    for (int i = 0; i < 4; i++) {
        printf("%d: %s\n", a[i].leg_count, a[i].name);
    }
}

Sıralanacak dizinizdeki iki öğeyi karşılaştırabilen bir fonksiyonu qsort()'a verdiğiniz sürece, her şeyi sıralayabilir. Ve bunu öğelerin türlerini hiçbir yere sabit olarak yazmaya (hardcode) gerek duymadan yapar. qsort(), geçirdiğiniz compar() fonksiyonunun sonuçlarına göre yalnızca bayt bloklarını yeniden düzenler.
