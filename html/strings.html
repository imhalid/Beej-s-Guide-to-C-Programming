7 Metin Dizileri (Strings)

Nihayet! String'ler (metin dizileri)! Bundan daha basit ne olabilir ki?

Şey, meğer C'de string'ler aslında bildiğimiz string'ler değilmiş. Aynen öyle! Onlar da pointer! Tabii ki öyleler!

Tıpkı diziler gibi, C'de string'ler de zar zor var olurlar.

Ama gelin inceleyelim—aslında o kadar da büyük bir olay değil.

7.1 String Sabitleri (String Literals)

Başlamadan önce C'deki string sabitleri (string literals) hakkında konuşalım. Bunlar çift tırnak (") içindeki karakter dizileridir. (Tek tırnaklar karakterleri kapsar ve tamamen farklı bir canlı türüdür.)

Örnekler:

"Hello, world!\n"
"This is a test."
"When asked if this string had quotes in it, she replied, \"It does.\""

İlki sonunda yeni satır karakteri içerir—görmesi oldukça yaygın bir şey.

Sonuncusu içinde tırnak işaretleri barındırır, ancak her birinin önünde bu noktada string'e literal bir tırnak işaretinin ait olduğunu belirten bir ters eğik çizgi (\) (kaçış karakteri / escaped) görürsünüz. C derleyicisi bir çift tırnak yazdırmak ile string'in sonundaki çift tırnak arasındaki farkı bu şekilde anlar.

7.2 String Değişkenleri

Artık bir string sabiti oluşturmayı bildiğimize göre, onunla bir şeyler yapabilmek için onu bir değişkene atayalım.

char *s = "Hello, world!";

Şu türe dikkat edin: char göstericisi (pointer to char). s string değişkeni aslında o string'deki ilk karaktere, yani H harfine bir pointer'dır.

Ve onu %s ("string" için) format belirteci ile yazdırabiliriz:

char *s = "Hello, world!";

printf("%s\n", s);  // "Hello, world!"

7.3 Dizi Olarak String Değişkenleri

Başka bir seçenek de yukarıdaki char* kullanımıyla neredeyse eşdeğer olan şudur:

char s[14] = "Hello, world!";

// veya tam anlamıyla tembellik edip derleyicinin
// uzunluğu bizim yerimize hesaplamasını istersek:

char s[] = "Hello, world!";

Bu, bir string'deki karakterlere erişmek için dizi notasyonunu kullanabileceğiniz anlamına gelir. Bir string'deki tüm karakterleri aynı satırda yazdırmak için tam olarak bunu yapalım:

#include <stdio.h>

int main(void)
{
    char s[] = "Hello, world!";

    for (int i = 0; i < 13; i++)
        printf("%c", s[i]);
    printf("\n");
}

Tek bir karakter yazdırmak için %c format belirtecini kullandığımıza dikkat edin.

Ayrıca şuna da bakın. s tanımını bir char* türü yapacak şekilde değiştirsek bile program yine sorunsuz çalışacaktır:

#include <stdio.h>

int main(void)
{
    char *s = "Hello, world!";   // Burası char*

    for (int i = 0; i < 13; i++)
        printf("%c", s[i]);    // Ama yine de dizileri mi kullanıyoruz...?
    printf("\n");
}

Ve ekrana yazdırırken işi halletmek için hala dizi notasyonunu kullanabiliyoruz! Bu şaşırtıcıdır, ancak sadece henüz dizi/pointer eşdeğerliği hakkında konuşmadığımız içindir. Bu da derinlerde dizilerin ve pointer'ların aynı şey olduğuna dair bir başka ipucudur.

7.4 String İlklendiricileri (String Initializers)

String değişkenlerini string sabitleriyle ilklendirmeye dair bazı örnekler görmüştük:

char *s = "Hello, world!";
char t[] = "Hello, again!";

Ancak bu iki ilklendirme ince bir şekilde birbirinden farklıdır. Bir string sabiti, bir tamsayı sabitine benzer şekilde, belleği derleyici tarafından sizin için otomatik olarak yönetilen bir şeydir! Bir tamsayı ile, yani sabit boyutlu bir veri parçasıyla, derleyici onu oldukça kolay yönetebilir. Ancak string'ler, derleyicinin bir bellek yığınına atıp size ona bir pointer vererek ehlileştirdiği değişken baytlı bir canavardır.

Bu biçim, o string'in yerleştirildiği yere işaret eder. Tipik olarak, performans ve güvenlik nedenleriyle o yer, programınızın belleğinin geri kalanından uzak bir diyardır – salt okunur bellek (read-only memory).

char *s = "Hello, world!";

Yani şu şekilde o string'i değiştirmeye (mutate etmeye) çalışırsanız:

char *s = "Hello, world!";

s[0] = 'z';  // KÖTÜ HABER: bir string sabitini değiştirmeye çalıştı!

Davranış tanımsızdır (undefined behavior). Muhtemelen sisteminize bağlı olarak bir çökme ile sonuçlanacaktır.

Ancak bunu bir dizi olarak tanımlamak farklıdır. Derleyici bu baytları şehrin başka bir yerine istiflemez, tam sokağın aşağısındadırlar. Bu, istediğimiz zaman değiştirebileceğimiz string'in değiştirilebilir bir kopyasıdır:

char t[] = "Hello, again!";  // t string'in dizi kopyasıdır
t[0] = 'z'; //  Problem yok

printf("%s\n", t);  // "zello, again!"

Bu yüzden unutmayın: Bir string sabitine pointer'ınız varsa onu değiştirmeye çalışmayın! Ve bir diziyi ilklendirmek için çift tırnaklı bir string kullanırsanız, bu aslında bir string sabiti değildir.

7.5 String Uzunluğunu Almak

Alamazsınız, çünkü C bunu sizin için takip etmez. Ve "alamazsınız" derken aslında "alabilirsiniz" demek istiyorum64. <string.h> içinde, herhangi bir string'in bayt cinsinden uzunluğunu hesaplamak için kullanılabilen strlen() adında bir fonksiyon vardır65.

#include <stdio.h>
#include <string.h>

int main(void)
{
    char *s = "Hello, world!";

    printf("The string is %zu bytes long.\n", strlen(s));
}

strlen() fonksiyonu size_t türünde bir değer döndürür; bu tamsayı türündedir, böylece tamsayı matematiği için kullanabilirsiniz. size_t türünü %zu ile yazdırırız.

Yukarıdaki program şunu yazdırır:

The string is 13 bytes long.

Harika! Yani string uzunluğunu almak mümkünmüş!

Ama… C hiçbir yerde string'in uzunluğunu takip etmiyorsa, string'in ne kadar uzun olduğunu nasıl biliyor?

7.6 String Sonlandırma (String Termination)

C string'leri diğer birçok programlama dilinden ve hatta neredeyse tüm modern programlama dillerinden biraz farklı yapar.

Yeni bir dil yaparken bir string'i bellekte saklamak için temel olarak iki seçeneğiniz vardır:

  1. String'in baytlarını, string'in uzunluğunu belirten bir sayı ile birlikte saklamak.

  2. String'in baytlarını saklamak ve string'in sonunu sonlandırıcı (terminator) adı verilen özel bir bayt ile işaretlemek.

255 karakterden uzun string'ler istiyorsanız 1. seçenek uzunluğu saklamak için en az iki bayt gerektirir. Oysa 2. seçenek string'i sonlandırmak için yalnızca tek bir bayt gerektirir. Yani orada ufak bir tasarruf var.

Elbette bugünlerde bir bayt (veya 3 bayt – çoğu dil memnuniyetle 4 gigabayt uzunluğunda string'lere izin verir) tasarruf etme konusunda endişelenmek komik görünüyor. Ama zamanında bu daha büyük bir olaydı.

Bu yüzden C 2. yaklaşımı benimsedi. C'de bir "string" iki temel özellikle tanımlanır:

  • String'deki ilk karaktere bir pointer (gösterici).
  • String'in sonunu gösteren, pointer'dan sonra belleğin bir yerindeki sıfır değerli bir bayt (veya NUL karakteri66).

Bir NUL karakteri C kodunda \0 olarak yazılabilir, ancak bunu sık sık yapmak zorunda kalmazsınız.

Kodunuza çift tırnak içinde bir string dahil ettiğinizde NUL karakteri otomatik ve örtük (implicit) olarak dahil edilir.

char *s = "Hello!";  // Arka planda aslında "Hello!\0"

Bunu aklımızda tutarak, bir NUL bulana kadar bir string'deki char'ları sayan kendi strlen() fonksiyonumuzu yazalım.

Prosedür, ilerledikçe sayarak tek bir NUL karakteri için string boyunca ileriye bakmaktır67:

int my_strlen(char *s)
{
    int count = 0;

    while (s[count] != '\0')  // Tek karakter için tek tırnak
        count++;

    return count;
}

Ve dahili strlen() fonksiyonu temel olarak işi bu şekilde halleder.

7.7 Bir String'i Kopyalamak

Atama operatörü (=) aracılığıyla bir string'i kopyalayamazsınız. Tüm yaptığı ilk karaktere olan pointer'ın bir kopyasını oluşturmaktır… böylece aynı string'e iki pointer ile kalakalırsınız:

#include <stdio.h>

int main(void)
{
    char s[] = "Hello, world!";
    char *t;

    // Bu pointer'ın kopyasını oluşturur, string'in kopyasını değil!
    t = s;

    // t'yi değiştiriyoruz
    t[0] = 'z';

    // Ama s'yi yazdırmak değişikliği gösterir!
    // Çünkü t ve s aynı string'i gösteriyor!

    printf("%s\n", s);  // "zello, world!"
}

Bir string'in kopyasını almak istiyorsanız onu her seferinde bir bayt kopyalamanız gerekir—bu, string'in münferit baytlarını bellekteki bir yerden alıp bellekteki başka bir yerde çoğaltacağınız anlamına gelir. Bu işlem strcpy() fonksiyonu ile kolaylaştırılmıştır.68

String'i kopyalamadan önce içine kopyalayacak yeriniz olduğundan emin olun, yani karakterleri tutacak hedef dizinin en az kopyaladığınız string kadar uzun olması gerekir.

#include <stdio.h>
#include <string.h>

int main(void)
{
    char s[] = "Hello, world!";
    char t[100];  // Her char bir bayttır, dolayısıyla bolca yer var

    // Bu string'in kopyasını oluşturur!
    strcpy(t, s);

    // t'yi değiştiriyoruz
    t[0] = 'z';

    // Ve s etkilenmeden kalır çünkü farklı bir string'dir
    printf("%s\n", s);  // "Hello, world!"

    // Ama t değişti
    printf("%s\n", t);  // "zello, world!"
}

strcpy() ile hedef pointer'ın ilk argüman, kaynak pointer'ın ise ikinci argüman olduğuna dikkat edin. Bunu hatırlamak için kullandığım anımsatıcı (hafıza tekniği), kaynak sağda ve hedef solda olmak üzere string'ler için atama = çalışsaydı t ve s diziliminin olacağı sıra olmasıdır.
