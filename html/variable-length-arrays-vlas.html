30 Değişken Uzunluklu Diziler (VLA'lar)

C, boyutu çalışma zamanında (runtime) belirlenen bir dizi tanımlamanıza imkan tanır. Bu, malloc() ile elde ettiğiniz dinamik çalışma zamanı boyutlandırmasının avantajlarını sunar, üstelik sonrasında belleği free() ile serbest bırakma derdi olmadan.

Şimdi, pek çok kişi VLA'ları pek sevmez. Örneğin Linux çekirdeğinden yasaklandılar. Bunun gerekçelerine daha sonra daha ayrıntılı olarak değineceğiz.

Bu, dilin isteğe bağlı bir özelliğidir. VLA'lar mevcut değilse __STDC_NO_VLA__ makrosu 1 olarak ayarlanır. (C99'da zorunluydular, ardından C11 ile isteğe bağlı hale geldiler.)

#if __STDC_NO_VLA__ == 1
   #error Sorry, need VLAs for this program!
#endif

Ancak ne GCC ne de Clang bu makroyu tanımlama zahmetine girmediğinden, bundan pek fazla yararlanamayabilirsiniz.

Gelin önce bir örnekle başlayalım, ardından detaylardaki şeytana bakarız.

30.1 Temel Bilgiler

Normal bir dizi, sabit bir boyutla şu şekilde tanımlanır:

int v[10];

Ancak VLA'lar ile, diziyi oluşturmak için çalışma zamanında belirlenen bir boyut kullanabiliriz, şöyle ki:

int n = 10;
int v[n];

Şimdi, bu aynı şeymiş gibi görünüyor ve birçok açıdan öyle, ancak bu size ihtiyacınız olan boyutu hesaplama ve ardından tam da o boyutta bir dizi elde etme esnekliği sağlar.

Kullanıcıdan dizinin boyutunu girmesini isteyelim ve ardından bu dizi elemanlarının her birinde indeks çarpı 10 değerini saklayalım:

#include <stdio.h>

int main(void)
{
    int n;
    char buf[32];

    printf("Enter a number: "); fflush(stdout);
    fgets(buf, sizeof buf, stdin);
    n = strtoul(buf, NULL, 10);

    int v[n];

    for (int i = 0; i < n; i++)
        v[i] = i * 10;

    for (int i = 0; i < n; i++)
        printf("v[%d] = %d\n", i, v[i]);
}

(7. satırda, sonunda bir yeni satır karakteri olmasa bile satırı çıktı vermeye zorlaması gereken bir fflush() var.)

12. satır, VLA'yı tanımladığımız yerdir—çalışma o satırı geçtiğinde, dizinin boyutu o anda n neyse ona ayarlanır. Dizi uzunluğu daha sonra değiştirilemez.

Köşeli parantezlerin içine bir ifade de koyabilirsiniz:

int v[x * 100];

Bazı kısıtlamalar:

  • Dosya kapsamında (file scope) bir VLA tanımlayamazsınız ve blok kapsamında static bir VLA yapamazsınız175.
  • Diziyi ilklendirmek için bir ilklendirme listesi (initializer list) kullanamazsınız.

Ayrıca, dizi boyutu için negatif bir değer girmek tanımsız davranışa (undefined behavior) yol açar—en azından bu evrende.

30.2 sizeof ve VLA'lar

sizeof operatörünün diziler de dahil olmak üzere belirli herhangi bir nesnenin bayt cinsinden boyutunu vermesine alışkınız. VLA'lar da bir istisna değildir.

Temel fark, bir VLA üzerinde sizeof işleminin çalışma zamanında (runtime) yürütülmesidir; oysa değişken boyutlu olmayan bir değişkende derleme zamanında (compile time) hesaplanır.

Ancak kullanımı aynıdır.

Hatta alışılagelmiş dizi hilesiyle bir VLA'daki eleman sayısını bile hesaplayabilirsiniz:

size_t num_elems = sizeof v / sizeof v[0];

Yukarıdaki satırdan çıkarılacak ince ve doğru bir anlam var: pointer aritmetiği tıpkı normal bir diziden bekleyeceğiniz gibi çalışır. O halde gönlünüzce kullanmaya devam edin:

#include <stdio.h>

int main(void)
{
    int n = 5;
    int v[n];

    int *p = v;

    *(p+2) = 12;
    printf("%d\n", v[2]);  // 12

    p[3] = 34;
    printf("%d\n", v[3]);  // 34
}

Normal dizilerde olduğu gibi, gerçekte bir VLA tanımlamadan olası bir VLA'nın boyutunu almak için sizeof() ile parantez kullanabilirsiniz:

int x = 12;

printf("%zu\n", sizeof(int [x]));  // Benim sistemimde 48 yazdırır

30.3 Çok Boyutlu VLA'lar

Bir veya daha fazla boyutu bir değişkene ayarlanmış her türlü VLA'yı yapmaya devam edebilirsiniz

int w = 10;
int h = 20;

int x[h][w];
int y[5][w];
int z[10][w][20];

Yine, bunlarda tıpkı normal bir dizide gezinir gibi gezinebilirsiniz.

30.4 Tek Boyutlu VLA'ları Fonksiyonlara Geçirmek

Tek boyutlu VLA'ları bir fonksiyona aktarmak, normal bir diziyi aktarmaktan farklı olmayabilir. Doğrudan yapabilirsiniz.

#include <stdio.h>

int sum(int count, int *v)
{
    int total = 0;

    for (int i = 0; i < count; i++)
        total += v[i];

    return total;
}

int main(void)
{
    int x[5];   // Standart dizi

    int a = 5;
    int y[a];   // VLA

    for (int i = 0; i < a; i++)
        x[i] = y[i] = i + 1;

    printf("%d\n", sum(5, x));
    printf("%d\n", sum(a, y));
}

Ancak işin içinde bundan biraz daha fazlası var. Ayrıca, önce boyutu geçirip ardından parametre listesinde o boyutu vererek C'ye dizinin belirli bir VLA boyutunda olduğunu bildirebilirsiniz:

int sum(int count, int v[count])
{
    // ...
}

Bu arada, yukarıdaki fonksiyon için bir prototip listelemenin birkaç yolu vardır; bunlardan biri, VLA'daki değeri özel olarak adlandırmak istemiyorsanız bir * içerir. Bu sadece türün normal bir pointer aksine bir VLA olduğunu gösterir.

VLA prototipleri:

void do_something(int count, int v[count]);  // İsimlerle
void do_something(int, int v[*]);            // İsimsiz

Yine, o * olayı yalnızca prototiple çalışır—fonksiyonun kendisinde açık boyutu koymanız gerekir.

Şimdi—çok boyutlu hale gelelim! Eğlence burada başlıyor.

30.5 Çok Boyutlu VLA'ları Fonksiyonlara Geçirmek

Yukarıdaki tek boyutlu VLA'ların ikinci biçimiyle yaptığımız şeyin aynısı, ancak bu sefer iki boyut geçiriyoruz ve bunları kullanıyoruz.

Aşağıdaki örnekte, değişken genişlik ve yükseklikte bir çarpım tablosu matrisi oluşturup ardından bunu yazdırması için bir fonksiyona geçiriyoruz.

#include <stdio.h>

void print_matrix(int h, int w, int m[h][w])
{
    for (int row = 0; row < h; row++) {
        for (int col = 0; col < w; col++)
            printf("%2d ", m[row][col]);
        printf("\n");
    }
}

int main(void)
{
    int rows = 4;
    int cols = 7;

    int matrix[rows][cols];

    for (int row = 0; row < rows; row++)
        for (int col = 0; col < cols; col++)
            matrix[row][col] = row * col;

    print_matrix(rows);
}

30.5.1 Kısmi Çok Boyutlu VLA'lar

Boyutlardan bazılarının sabit, bazılarının ise değişken olmasını sağlayabilirsiniz. Diyelim ki 5 eleman olarak sabitlenmiş bir kayıt uzunluğumuz var, ancak kaç kayıt olduğunu bilmiyoruz.

#include <stdio.h>

void print_records(int count, int record[count][5])
{
    for (int i = 0; i < count; i++) {
        for (int j = 0; j < 5; j++)
            printf("%2d ", record[i][j]);
        printf("\n");
    }
}

int main(void)
{
    int rec_count = 3;
    int records[rec_count][5];

    // Bazı sahte verilerle doldur
    for (int i = 0; i < rec_count; i++)
        for (int j = 0; j < 5; j++)
            records[i][j] = (i+1)*(j+2);

    print_records(rec_count, records);
}

30.6 Normal Dizilerle Uyumluluk

VLA'lar bellekte tıpkı normal diziler gibi olduğundan, boyutlar eşleştiği sürece bunları birbirinin yerine geçirmek tamamen kabul edilebilirdir…

Örneğin, özellikle bir \(3\times5\) dizisi isteyen bir fonksiyonumuz varsa, içine yine de bir VLA geçirebiliriz.

int foo(int m[5][3]) {...}

\\ ...

int w = 3, h = 5;
int matrix[h][w];

foo(matrix);   // Tamam!

Aynı şekilde, bir VLA fonksiyonunuz varsa, içine normal bir dizi geçirebilirsiniz:

int foo(int h, int w, int m[h][w]) {...}

\\ ...

int matrix[3][5];

foo(3, 5, matrix);   // Tamam!

Yine de dikkatli olun: boyutlarınız uyuşmuyorsa, muhtemelen bazı tanımsız davranışlarla (undefined behavior) karşılaşırsınız.

30.7 typedef ve VLA'lar

Bir VLA'yı typedef ile tanımlayabilirsiniz, ancak davranış beklediğiniz gibi olmayabilir.

Temel olarak typedef, değerleri typedef çalıştırıldığı andaki halleriyle olan yeni bir tür oluşturur.

Yani bu bir VLA'nın typedef'i olmaktan ziyade, o andaki boyutlara sahip yeni bir sabit boyutlu dizi türüdür.

#include <stdio.h>

int main(void)
{
    int w = 10;

    typedef int goat[w];

    // goat 10 int'lik bir dizidir
    goat x;

    // Sayıların kareleriyle ilklendir
    for (int i = 0; i < w; i++)
        x[i] = i*i;

    // Bunları yazdır
    for (int i = 0; i < w; i++)
        printf("%d\n", x[i]);

    // Şimdi w'yi değiştirelim...

    w = 20;

    // Ancak goat HALA 10 int'lik bir dizidir, çünkü typedef
    // çalıştığında w'nin değeri oydu.
}

Yani sabit boyutlu bir dizi gibi davranır.

Ancak yine de üzerinde bir ilklendirme listesi kullanamazsınız.

30.8 Atlama Tuzakları

VLA'ların yakınında goto kullanırken dikkatli olmalısınız çünkü pek çok şey yasal değildir.

Ve longjmp() kullanırken VLA'lar ile bellek sızıntısı yaşayabileceğiniz bir durum vardır.

Ancak bu iki konuyu da ilgili bölümlerinde ele alacağız.

30.9 Genel Sorunlar

VLA'lar birkaç nedenden dolayı Linux çekirdeğinde yasaklanmıştır:

  • Kullanıldıkları pek çok yer sadece sabit boyutlu olmalıydı.
  • VLA'ların arkasındaki kod daha yavaştır (çoğu insanın fark etmeyeceği kadar, ancak bir işletim sisteminde fark yaratan derecede).
  • VLA'lar tüm C derleyicileri tarafından aynı derecede desteklenmez.
  • Yığın (stack) boyutu sınırlıdır ve VLA'lar yığına yerleşir. Bir kod yanlışlıkla (veya kötü niyetle) bir VLA tahsis eden bir çekirdek fonksiyonuna büyük bir değer geçirirse, Kötü Şeyler™ yaşanabilir.

İnternetteki diğer kişiler, bir VLA'nın tahsis edilememe durumunu tespit etmenin hiçbir yolu olmadığını ve bu tür sorunlardan muzdarip programların muhtemelen çökeceğini belirtiyor. Sabit boyutlu diziler de aynı soruna sahip olsa da, birinin yanlışlıkla, diyelim ki 30 megabaytlık sabit boyutlu bir dizi tanımlamasından ziyade, yanlışlıkla Olağandışı Boyutta Bir VLA oluşturması çok daha olasıdır.
