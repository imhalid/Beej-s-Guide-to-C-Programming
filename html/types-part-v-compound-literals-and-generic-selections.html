32 Türler Bölüm V: Bileşik Sabitler ve Jenerik Seçimler

Bu, türler için son bölüm! İki şey hakkında konuşacağız:

  • İsimsiz "anonim" nesnelere nasıl sahip olunacağı ve bunun nasıl yararlı olduğu.
  • Türe bağlı kodun nasıl üretileceği.

Bunlar birbiriyle pek ilgili değiller, ama her ikisi de tek başlarına birer bölümü hak etmiyorlar. Ben de bir asi gibi onları buraya tıkıştırdım!

32.1 Bileşik Sabitler (Compound Literals)

Bu, bir türün nesnesini bir değişkene atamadan anında (on the fly) oluşturmanıza olanak tanıyan harika bir dil özelliğidir. Basit türler, diziler, struct'lar, aklınıza ne gelirse oluşturabilirsiniz.

Bunun ana kullanımlarından biri, değeri tutmak için geçici bir değişken oluşturmak istemediğinizde fonksiyonlara karmaşık argümanlar geçirmektir.

Bileşik bir sabit (compound literal) oluşturmanın yolu, tür adını parantez içine almak ve ardından bir başlangıç değeri listesi (initializer list) koymaktır. Örneğin, isimsiz bir int dizisi şöyle görünebilir:

(int []){1,2,3,4}

Şimdi, bu kod satırı kendi başına bir şey yapmaz. 4 tane int elemandan oluşan isimsiz bir dizi oluşturur ve ardından bunları kullanmadan çöpe atar.

Diziye bir başvuru (referans) saklamak için bir pointer kullanabilirdik…

int *p = (int []){1 ,2 ,3 ,4};

printf("%d\n", p[1]);  // 2

Ama bu bir diziye sahip olmak için biraz dolambaçlı bir yol gibi görünüyor. Yani, sadece şunu da yapabilirdik179:

int p[] = {1, 2, 3, 4};

printf("%d\n", p[1]);  // 2

Öyleyse daha yararlı bir örneğe göz atalım.

32.1.1 İsimsiz Nesneleri Fonksiyonlara Geçirme

Bir int dizisini toplayan bir fonksiyonumuz olduğunu varsayalım:

int sum(int p[], int count)
{
    int total = 0;

    for (int i = 0; i < count; i++)
        total += p[i];

    return total;
}

Onu çağırmak isteseydik, normalde fonksiyona geçirmek için bir dizi bildirip içine değerler saklayarak şuna benzer bir şey yapmamız gerekirdi:

int a[] = {1, 2, 3, 4};

int s = sum(a, 4);

Fakat isimsiz nesneler, değişkenden tamamen kaçınarak onu doğrudan fonksiyon çağrısına geçirmemize olanak tanır (yukarıda listelenen parametre adları). İnceleyin—a değişkenini ilk argüman olarak geçirdiğimiz isimsiz bir dizi ile değiştireceğiz:

//                   p[]         count
//           |-----------------|  |
int s = sum((int []){1, 2, 3, 4}, 4);

Bayağı şık!

32.1.2 İsimsiz struct Yapıları

struct'lar ile de benzer bir şey yapabiliriz.

İlk olarak, isimsiz nesneler kullanmadan işleri yapalım. Bazı x/y koordinatlarını tutacak bir struct tanımlayacağız. Ardından bir tane oluşturup başlatıcı listesine (initializer) değerler geçireceğiz. Son olarak, değerleri yazdırmak için onu bir fonksiyona geçireceğiz:

#include <stdio.h>

struct coord {
    int x, y;
};

void print_coord(struct coord c)
{
    printf("%d, %d\n", c.x, c.y);
}

int main(void)
{
    struct coord t = {.x=10, .y=20};

    print_coord(t);   // "10, 20" yazdırır
}

Yeterince açık, değil mi?

Şimdi print_coord() fonksiyonuna geçirdiğimiz t değişkeni yerine isimsiz bir nesne kullanacak şekilde değiştirelim.

t değişkenini oradan çıkarıp yerine isimsiz bir struct koyacağız:

    //struct coord t = {.x=10, .y=20};

    print_coord((struct coord){.x=10, .y=20});   // "10, 20" yazdırır

Hala çalışıyor!

32.1.3 İsimsiz Nesnelere Pointer'lar

Son örnekte, bir struct kullanıyor olmamıza rağmen, print_coord() fonksiyonuna struct pointer'ı geçirmek yerine struct'ın bir kopyasını geçirdiğimizi fark etmiş olabilirsiniz.

Görünüşe göre, her zamanki gibi & ile isimsiz bir nesnenin adresini alabiliriz.

Bunun nedeni, genel olarak, bir operatör o türdeki bir değişken üzerinde çalışacaksa, o operatörü o türdeki isimsiz bir nesne üzerinde de kullanabilmenizdir.

Yukarıdaki kodu isimsiz bir nesneye pointer geçirecek şekilde değiştirelim:

#include <stdio.h>

struct coord {
    int x, y;
};

void print_coord(struct coord *c)
{
    printf("%d, %d\n", c->x, c->y);
}

int main(void)
{
    //     & işaretine dikkat edin
    //          |
    print_coord(&(struct coord){.x=10, .y=20});   // "10, 20" yazdırır
}

Ayrıca bu, basit nesnelere bile pointer geçirmek için güzel bir yol olabilir:

// Değeri 3490 olan bir int'e pointer geçirin
foo(&(int){3490});

İşte bu kadar kolay.

32.1.4 İsimsiz Nesneler ve Kapsam

İsimsiz bir nesnenin yaşam süresi (lifetime), kendi kapsamının (scope) sonunda biter. Bunun canınızı yakabileceği en büyük durum, yeni bir isimsiz nesne oluşturup ona bir pointer elde ettiğinizde ve ardından nesnenin kapsamından çıktığınızda gerçekleşir. Bu durumda pointer ölü bir nesneye başvuracaktır.

Yani bu tanımsız davranıştır (undefined behavior):

int *p;

{
    p = &(int){10};
}

printf("%d\n", *p);  // GEÇERSİZ: (int){10} kapsam dışına çıktı

Aynı şekilde, bir fonksiyondan isimsiz bir nesneye pointer döndüremezsiniz. Nesne kapsam dışına çıktığında bellekten kaldırılır:

#include <stdio.h>

int *get3490(void)
{
    // Bunu yapmayın
    return &(int){3490};
}

int main(void)
{
    printf("%d\n", *get3490());  // GEÇERSİZ: (int){3490} kapsam dışına çıktı
}

Kapsamlarını sıradan bir yerel değişkenin kapsamı gibi düşünün. Sıradan bir yerel değişkene de pointer döndüremezsiniz.

32.1.5 Saçma Bir İsimsiz Nesne Örneği

Oraya istediğiniz herhangi bir türü koyabilir ve isimsiz bir nesne oluşturabilirsiniz.

Örneğin, şunlar fiilen eşdeğerdir:

int x = 3490;

printf("%d\n", x);               // 3490 (değişken)
printf("%d\n", 3490);            // 3490 (sabit)
printf("%d\n", (int){3490});     // 3490 (isimsiz nesne)

Bu sonuncusu isimsizdir, ama saçmadır. Bir önceki satırdaki basit olanı yapmak varken.

Ama umarım bu, sözdizimi konusunda biraz daha açıklık sağlar.

32.2 Jenerik Seçimler (Generic Selections)

Bu, ifadenin ilk argümanının türüne bağlı olarak farklı kod parçalarını seçmenize olanak tanıyan bir ifadedir.

Birazdan bir örneğe bakacağız, ancak bunun çalışma zamanında değil, derleme zamanında işlendiğini bilmek önemlidir. Burada çalışma zamanı analizi yapılmamaktadır.

İfade _Generic ile başlar, bir nevi switch gibi çalışır ve en az iki argüman alır.

İlk argüman bir türe sahip bir ifade (veya değişkendir180). Tüm ifadelerin bir türü vardır. _Generic ifadesinin kalan argümanları, ilk argüman o türdeyse ifadenin sonucu yerine neyin konulacağına dair durumlardır (cases).

Ne?

Deneyelim ve görelim.

#include <stdio.h>

int main(void)
{
    int i;
    float f;
    char c;

    char *s = _Generic(i,
                    int: "that variable is an int",
                    float: "that variable is a float",
                    default: "that variable is some type"
                );

    printf("%s\n", s);
}

Satır 9'da başlayan _Generic ifadesine göz atın.

Derleyici bunu gördüğünde ilk argümanın türüne bakar. (Bu örnekte i değişkeninin türü.) Ardından bu türde bir şey için durumlara (cases) bakar. Ve sonra tüm _Generic ifadesinin yerine o argümanı koyar.

Bu durumda i bir int türüdür, dolayısıyla o durumla eşleşir. Ardından ifadenin yerine string konulur. Dolayısıyla derleyici gördüğünde satır şuna dönüşür:

    char *s = "that variable is an int";

Derleyici _Generic içinde bir tür eşleşmesi bulamazsa, isteğe bağlı default durumuna bakar ve onu kullanır.

Bir tür eşleşmesi bulamazsa ve default yoksa, bir derleme hatası alırsınız. İlk ifade türlerden biriyle veya default ile kesinlikle eşleşmelidir.

Tekrar tekrar _Generic yazmak zahmetli olduğundan, genellikle kolayca ve defalarca yeniden kullanılabilen bir makronun gövdesini oluşturmak için kullanılır.

Bir argüman alan ve argümanın türünü içeren bir string döndüren TYPESTR(x) makrosu yapalım.

Böylece örneğin TYPESTR(1) ifadesi "int" string'ini döndürecektir.

Başlıyoruz:

#include <stdio.h>

#define TYPESTR(x) _Generic((x), \
                        int: "int", \
                        long: "long", \
                        float: "float", \
                        double: "double", \
                        default: "something else")

int main(void)
{
    int i;
    long l;
    float f;
    double d;
    char c;

    printf("i is type %s\n", TYPESTR(i));
    printf("l is type %s\n", TYPESTR(l));
    printf("f is type %s\n", TYPESTR(f));
    printf("d is type %s\n", TYPESTR(d));
    printf("c is type %s\n", TYPESTR(c));
}

Bu şu çıktıyı verir:

i is type int
l is type long
f is type float
d is type double
c is type something else

Ki bu sürpriz olmamalı, çünkü söylediğimiz gibi, main() içindeki o kod derlendiğinde şununla değiştirilir:

    printf("i is type %s\n", "int");
    printf("l is type %s\n", "long");
    printf("f is type %s\n", "float");
    printf("d is type %s\n", "double");
    printf("c is type %s\n", "something else");

Ve gördüğümüz çıktı tam olarak budur.

Bir tane daha yapalım. Buraya bazı makrolar dahil ettim, böylece şunu çalıştırdığınızda:

int i = 10;
char *s = "Foo!";

PRINT_VAL(i);
PRINT_VAL(s);

şu çıktıyı elde edersiniz:

i = 10
s = Foo!

Bunu yapmak için biraz makro sihirbazlığından yararlanmamız gerekecek.

#include <stdio.h>
#include <string.h>

// Bir tür için format belirteci veren makro
#define FMTSPEC(x) _Generic((x), \
                        int: "%d", \
                        long: "%ld", \
                        float: "%f", \
                        double: "%f", \
                        char *: "%s")
                        // TODO: daha fazla tür ekle
                        
// "ad = değer" biçiminde bir değişken yazdıran makro
#define PRINT_VAL(x) do { \
    char fmt[512]; \
    snprintf(fmt, sizeof fmt, #x " = %s\n", FMTSPEC(x)); \
    printf(fmt, (x)); \
} while(0)

int main(void)
{
    int i = 10;
    float f = 3.14159;
    char *s = "Hello, world!";

    PRINT_VAL(i);
    PRINT_VAL(f);
    PRINT_VAL(s);
}

çıktısı için:

i = 10
f = 3.141590
s = Hello, world!

Tüm bunları tek bir büyük makroya sığdırabilirdik, ama göz kanamasını önlemek için ikiye böldüm.
